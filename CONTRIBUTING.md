# Contributing

Issues and pull requests are welcome. Search existing issues first, then open a bug report, feature request, or blank issue. Report security vulnerabilities privately as described in `SECURITY.md`.

For code changes, create a descriptive branch in your fork, keep the change focused, and run `npm test` before opening a pull request. Do not edit generated files under `plugins/caveman` directly; update the importer or ThinkHome integration and run `npm run build`.

Upstream Caveman improvements belong upstream when generic. ThinkHome marketplace packaging stays downstream.
