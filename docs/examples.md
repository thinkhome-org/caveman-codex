# Examples

```text
$caveman ultra
Review this diff for correctness and security.
```

```text
$caveman-commit
Draft a Conventional Commit message for the staged changes.
```

```text
$caveman-migrate
Show the dry-run migration plan for /work/legacy-project.
```

For an untrusted or disabled hook, invoke `$caveman full` in the task directly. The same skills work in Codex Desktop, CLI, and IDE where plugin support is available.
