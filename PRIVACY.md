# Privacy

ThinkHome Caveman for Codex collects no telemetry, analytics, crash reports, credentials, or personal data. Its hooks process bounded Codex event JSON locally and store only the selected Caveman mode in Codex's plugin data directory.

Skills act only when selected and use the permissions already granted to Codex. `$caveman-init` may update a user-approved project's rule file, and `$caveman-compress` may update user-selected Markdown files while following their documented dry-run, backup, and validation rules. The packaged MCP shrink source is disabled unless a user explicitly configures it.

GitHub and OpenAI services used to download or run the plugin are governed by their own privacy policies. Report a privacy concern through the repository's private security reporting channel.
